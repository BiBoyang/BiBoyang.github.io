# 写在前面

这本册子是一份财报 RAG 系统的建设记录，不是教程。

它从一份 119 页的腾讯 2025 年中报进系统开始，沿着「抽取 → 清洗 → 分片 → 标注 → 索引 → 检索 → 生成」这条链路一路走到底，把每一环踩过的坑和坑换来的判断写下来。全册分四卷：数据上游、检索的错觉、从能跑到能扛、边界与展望。

## 这本书不是什么

它不是 RAG 入门。市面上讲 RAG 的书会从「什么是向量检索」开始，这本不会——它假设你已经跑通过 demo，正在把 demo 变成能上线的东西，然后发现每一步都不对劲。

它也不是一份可以照抄的配置清单。书里的每个数字都带着前提：`pdftotext` 在多栏页面上 20–30% 的错位，是这一份中报上的经验值；800–1200 token 的 chunk 区间，是这一个库上试出来的；M1 Pro 32GB 上跑 Qwen3-Embedding 的分档，换台机器结论就变。**结论会过期，方法不会。**

## 四种读法

- **库还没搭、数据还脏**：从「数据上游」卷顺序读，一路到「Metadata 设计」。
- **数据干净了，检索不准**：直接跳「检索的错觉」卷，时间、口径、相似度、混合、精排五个错觉挨个查。
- **已经上线，要扛住**：看「从能跑到能扛」卷，多市场架构、选型、参数、评估、排查、运维。
- **想判断边界和方向**：读「边界与展望」卷，Agent、GraphRAG、通用模式、三年演进、未来。建议读完全卷再来。

「数据上游」卷第 01 篇是全册地图，任何时候迷路都可以回到那里。

## 关于正文里的「第 N 篇」

这些章节最初是双周刊上的连载文章，篇号按发布顺序编，和册内章节号不一致（比如评估那篇是首发，在册子里却排在中段）。成册时保留了原篇号做 slug，正文内的互指已按册内章节号改写。
