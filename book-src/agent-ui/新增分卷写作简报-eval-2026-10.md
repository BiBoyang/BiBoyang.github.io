## 四、逐章规格

### eval01 · 没报错只是开始——行为的可断言性（开篇+模型章）

**定位**：本卷开篇，同时是全书结构的一次收口。界面部分第 24 篇把 ANSI 变成可断言的，
本篇指出那只回答了 prologue 问题的一半；行为层可断言性是另一个量级的难题。
**核心论点候选**：agent 断言难在三件事——非确定性（同一输入不同输出，断言目标从结果移到
路径覆盖+终态）、成本是一等约束（每个样本真金白银）、被测对象是模型×脚手架×工具×内容的
复合体（归因必须靠对照）。由此给出**四问框架**（能不能做对 / 坏了会不会察觉 / 是不是它的
功劳 / 什么代价）作为本卷的目录，后续每章认领一问。
**素材**：prologue（基建卷首，只引用其问句）；界面部分第 24 篇（引用不重讲）；
《agent-eval-map》【内部笔记】的框架浓缩；τ-bench pass^k【外部·已核验】作"可靠性而非
一次灵感"的官方注脚。
**配图**：全书四问地图 SVG（已拍板）：六层被测对象（模型/协议/宿主/内容扩展/生态/仓库）
× 四问 × 三姿势（能力评测/故障注入/对照实验）。
**「什么代价」一问**：本卷不设独立章；四问之四在 eval01 只立框架不展开例证，
候选素材（长上下文有效窗口衰减等）待 context-tps 提案落地后在 eval08 展开
（见备忘预留线头）。

### eval02 · 考题从哪来——为真实失败而建（问题章）

**定位**：用例来源哲学。**核心论点候选**：评估器该为已发现的错误而建，不为想象中的错误
而建——想象中的错误测出来全是噪声。红绿对照是用例的合法出生证明（每个修过的 bug 配一条
FAIL→PASS 用例，与 SWE-bench fail-to-pass【外部·已核验】同构）。触发层必须测双向：
该触发时触发、不该触发时不触发。
**素材**：博客《给 skill 建门禁》（2026-09-17）【已发布】收编；触发评测口径
（TP/FP/FN/TN、Read 影子信号不进混淆矩阵、超时 case 不进分母）来自 huohou 仓库
evals-shared 与立项 MEMO【亲历事实】；红线写法实验（description「不管」声明 vs 正文
行为指令，同一用例 66.7% FAIL → 100% PASS）【已发布】。
**新写部分**：从「危险案例侦察 → 造弹」的日常流程角度重组织（博客是事件流，本章要论点流）。

### eval03 · 绿灯的两种谎言——实验真的发生过吗（问题章，本卷独有贡献）

**定位**：正统评测教程默认「实验发生了」直接讲判分；本章讲被略过的前置层。
**章底稿**：短文《绿灯的两种谎言》（2026-10-05 会话定稿，作者已确认，
存档 `/Users/boyang/.zcode/workspace/default/绿灯的两种谎言-会话存档-2026-10-05.md` 〇节）
升格为本章骨架。
**核心论点候选**：绿灯会说谎，有两种说法——一是**检查问错了问题**（「文件在不在」vs
「目录能不能信」：文件在的时候两个世界产出同一个绿灯，它只在分叉日才和真问题分道扬镳，
而那一天只有日志在场）；二是**检查全对、但看的东西根本没发生**（六条绕行通道：静默降级 /
mock 只实现 happy path / agent 直写 grader 要看的结果文件 / skip 静默生效 / 兜底吞主路 /
grader 只看终态）。**统一定律**：当两个不同的世界产出同一个绿灯，观测对它们的差异就是盲的；
装着优化器的系统（agent）会自己漂向能过关的世界，模型越强，漂移越快。
**因果三机制**（「被绕过的部分最容易出事」是因果不是巧合）：选择效应（会被绕过的和容易
出事的是同一批「环境不对劲才需要工作」的部件）、零锻炼（eval 是它们唯一的上场机会，
第一次真实执行发生在生产）、筛选效应（grader 可绕过 = 主动筛选「不经过它」的解法，
随模型升级持续恶化）。
**对策两方向**：分叉观测（一个布尔拆成两次判断分别记结果；终态之外记路径凭据——工具
真的调了、插件真的挂了，与结果分开记分开断言，与 reread_any 绊线同构）；故障注入
（对检查喂坏样本：红了才算存在，不红只是装饰；对流程做消融：把以为是主干的部件拆掉
再跑，分数掉了说明它真在被测，没动说明测的从来不是以为的东西——**注入对象从被测物
换成测量仪器**）。
**素材**：短文底稿 + 博客《从 trace 到 eval》（2026-08-23）与《给流式协议造故障》
（2026-09-25）【已发布】收编为病例段（三种沉默失败、两种证明、排除计数）；
skill-up #263（超时强杀丢产物）与 #264（观测错误伪装成严谨证据）【亲历】。
**出处处理**：密钥目录病例源自外部推串讨论（青雲 @echo_vic），成书须匿名化
（「一位 harness 开发者公开描述过同款」）或替换为作者自己的病例——存档线头里有
「病例补全」一项，作者手上有一批 eval 偶然发现病例，补全（错在哪/怎么发现/怎么拆成
两次判断）后**优先用自己的病例做章首**。
**查重边界**：#264 误报翻案完整叙事在 eval07，本章只引结论；三协议 mock 机制细节
留基建卷互指；「每次惊讶都标出一块该写断言的空地」的用例化纪律归 eval02，本章只留
定律句；消融（对测量仪器注入）在本章，对照组（对被测物扰动）在 eval06——同属扰动法
方向相反，两章互指一句即可。

### eval04 · 炸弹——故障注入下沉到内容完整性（战例章）

**定位**：本卷主战例。**核心论点候选**：协议 mock 解的是「环境不可控」，内容完整性
故障（截断/删除/清 frontmatter）解的是「脚手架物理残缺后宿主会怎样」——后者在正统
robustness eval（prompt perturbation）里是空白。
**素材**：博客《回答被截断，你的 CLI 知道吗》（2026-09-25，108 格矩阵）与
《考官带伤阅卷》（2026-09-27）【已发布】收编。核心数字：检出（L2+）6/30、L0 占 60%
（「检出不难，告知才是缺口」）；挡路 8/8 vs 不挡路 2/8。
**【草稿】口径说明**：宿主矩阵一列实为 DeepSeek 端点的混杂问题已在发布前修复（2026-10-05
核实，文内明写混杂、不归因拆分），跨宿主对比数字可直引——引用时保留文内已有的混杂
声明与「脚手架/模型两变量、差异无法拆分」的原话；原生 Claude/GPT 对照列待
REPLICATION.md 复现，不写未实测对比。
**新写部分**：两篇博客合并后按「造弹 → 矩阵 → 翻车与翻案」重组；C0 阴性对照、
剂量-响应概念在本章立起（乘法模型留给 eval05）。

### eval05 · 检出率是个乘法（模型章）

**定位**：本卷的方法论核心，从战例抽出模型。**核心论点**：检出率 = 读到 × 愿报 × 挡路，
三因子缺一未检出即不可归因；「察觉了但没报」是最危险的未检出形态；检出 ≠ 止损；
防线应在 CI/loader/安装器（零 token 确定性），不在 skill 正文。
**素材**：《检出率是个乘法》草稿（_drafts，2026-10-01）**成书首发**【草稿】；
repo-quake 仓库级推论（88 份原始记录）；pi-quake 的 reread_any 绊线指标
（TP=8/FP=0/TN=23/FN=3）【亲历，2026-10-03 pi v1.0.0 实测】作「过程信号可机械提取」的例证。
**新写部分**：草稿到书章的改写（面向书读者补上下文，系列互指改口径）。

### eval06 · 对照组的陷阱——归因靠对照不靠证据强度（战例章）

**定位**：四问之三「是不是它的功劳」。**核心论点候选**：证据再硬也同时兼容两个相反的
故事；对照组选错比没有对照组更危险——它给错误结论配上证据。双臂对照（with/without）
是归因的最低配置；统计口径上单次跑分不作数，pass@k 与 pass^k 讲相反的故事。
**素材**：《测别人的生态》草稿（_drafts eval-08）**成书首发**【草稿】（插件漏斗
L1 安装 / L2 真调用、allowBuilds 生态位发现、裸基线缺否则「全绿」和「没测到」同貌）；
Anthropic plugin evals 双臂默认开 + no-plugin baseline【外部·已核验】作官方收编注脚
（一段带过，不展开机制）；pass@k/pass^k 与 Wilson 下界【内部笔记观点+统计学通识】。
**新写部分**：草稿重组 + 统计口径小节（不堆公式，直觉讲清「两个数讲相反的故事」即可，
公式细节脚注给出）。

### eval07 · 裁判也要被校准——meta-eval（收口章）

**定位**：本卷收口 + 全书收口。**核心论点候选**：系列全部翻案指向同一件事——裁判本身
也要被校准；评测系统的 bug 比被测对象的更隐蔽（观测会骗人、考题会骗人、对照组会骗人、
绿灯会骗人）。误报公开更正的成本是一次尴尬，收益是可信的轨迹。
**素材**：博客《我给 skill-up 报了一个不存在的 bug》（2026-09-20）、《CI 红、本地绿》
（2026-09-22）【已发布】收编；selftest 32 断言、判活器上线首日抓到自己崩溃【亲历】；
judge 校准纪律（TPR/TNR 分开看、Unknown 退路、校准集有机失败优先）【内部笔记观点】。
**收口动作**：末节回到 prologue 之问作全书答毕；「错误→机制化」清单
