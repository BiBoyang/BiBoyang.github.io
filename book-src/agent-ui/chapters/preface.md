# 写在前面

前阵子看到有人在讨论 Agent 的 TUI 和 GUI，两派吵得挺热闹。

我刚好两边都做过算是比较深入的研究，用 swift 从零开始写过一个 TUI 渲染引擎（ForgeLoopTUI），也写过 iOS 上的 Agent GUI 客户端。在创作和优化性能的过程中，记录下来不少的笔记和代码，以及各种踩坑和思考。

写这组文章之前，我翻了一遍自己攒下来的东西：项目源码、调试笔记、性能分析记录、读过的博客和开源库的源码、知乎上的相关讨论。散在好几个文件夹里，有些是完整的文档，有些只是当时随手记的片段。觉得这些东西放着也是放着，不如整理出来。

于是重新梳理了一遍，缺的地方补研究，浅的地方往下挖，写成了这本小册。全书按方向分四个部分，连起来是一条从界面挖到地基、再回头检验的路线：**界面**讲怎么把东西画出来，从 ANSI 转义序列、Markdown 流式渲染的 O(n²) 陷阱，到权限和 diff 的 UX 设计、多端架构；**胶水层**和**基建**再往下挖，讲连接、会话和协议边界，把界面撑起来的那半边；**评测**回答最后一个问题：建起来之后，怎么证明它真的在工作。书里的结论都拿我自己的引擎 ForgeLoopTUI 和各家 agent 的源码对过账——对账对出来的错，多半先错在我自己身上。

这本册子会持续更新，不是写完就算完的那种：方向挖到哪，部分就长到哪；已经写下的内容也可能更正——发现写错的会改，判断变了的会补记。另外，目录编号只是写作顺序，不是阅读顺序，按目录从上往下读就行。

不是什么权威结论，就是一个人同时踩过 TUI 和 GUI 两条船之后，把踩过的坑和想清楚的事记下来。如果恰好对你有用，那就最好了。
